# Clipping-papers

刚性折纸（rigid origami）实验代码：复现论文 **《Flexible quadrilateral mesh of isogonal type in arbitrary size》** —— Yang Liu, Jinsan Cheng, *ACM Transactions on Graphics* 37(4), Article 111, 2018（SIGGRAPH 2018）。

## 演示

当前 3×3 版本：中心和四角共 **5 个 60°/120° 菱形**，上、左、下、右共 **4 个正方形**，所有边长均为 1。先把旧排布的四角菱形各旋转 **90°**，再通过倾斜的正方形拼成三维铰接网格，最后在中心面固定的条件下折叠、返回。初态和末态均不要求九个面共面。

![菱形与正方形 3×3 折叠动画](origami_grid3x3_rhombi_squares.gif)

左侧固定展示**完整共边连接的初始三维拼接**，右侧从完全相同的初始姿态开始折叠。两侧都采用侧上方 40° 的视角（方位角 −85°），并同步放大，使用相同的坐标范围、缩放和正交投影，便于比较。中心和四角五个菱形均为同一种蓝色，四个正方形为橙色；正方形与相邻菱形具有非零面间夹角。视角由代码顶部的 `VIEW_ELEVATION`、`VIEW_AZIMUTH`、`VIEW_ZOOM` 控制。

## 当前版本的几何与折叠

- 中心菱形顶点按左上、左下、右下、右上排列，内角 λ 为 60°、120°、60°、120°。四角模板先绕自身中心旋转 90°，再选择靠近中心面的角作为拼接顶点。因此角面在该顶点处的角 μ 改为 **μ=λ**，旧排布则为 μ=180°−λ。这是实际的连接角变化。
- 每个内部顶点连接中心菱形、两个正方形和一个角菱形，扇形角为 λ、90°、λ、90°，总和交替为 300° 和 420°。此模型是非共面的铰接面片组装，不能作为一张无缺口、无重叠的平铺纸张。
- 内部模板数据中的五个菱形方向相同；三维组装时会再对这些模板进行刚性旋转和平移，使公共边重合。组装后的菱形法向及其二维投影不要求彼此相同。
- 动画显示有符号铰链转角 **ρ**，顺序为 T/L/B/R（上/左/下/右），参考零点是该正方形位于中心平面外侧的姿态。正转角初始朝 +z，负转角朝 −z。这个参考姿态不代表九个面可以同时平铺，也不是按论文上侧/下侧约定测量的二面角 α。
- 令 x=tan(ρ/2)。新的闭合约束为 `cos(λ) * (1 + (x_i*x_j)²) − 2*x_i*x_j = 0`。采用分支 `(x_T, x_L, x_B, x_R) = (t, q/t, −t, −q/t)`，其中 `q=2−√3`。它使四个正方形联动，保持四角菱形刚性。
- 默认初态 T/L/B/R 约为 +54.736°/+54.736°/−54.736°/−54.736°；默认末态约为 +130°/+14.244°/−130°/−14.244°。这是所选的演示范围，不代表运动极限；可用 `--min-angle` 和 `--max-angle` 调节，须满足 `0 < min-angle < max-angle < 180`。不会把末态强制压到一个平面。
- 角面使用正交坐标架之间的旋转和平移构造。导出前检查旋转后模板的边方向、连接顶点内角，以及逐帧的六个顶点间距离、内角、面片平面性、12 条公共边的两端重合情况；另外检查初态和末态各公共边两侧面片均不共面。
- 模型采用理想零厚度面片。逐帧检查横向穿面，但不构成连续时间、共面重叠或有限厚度碰撞的完整证明；未实现厚板铰链和接触力学。

## 折叠方式是否唯一

**当前已确定的初始空间拼接，在非退化姿态附近只有一个自由度。** 在当前分支上，选定 `t=tan(ρ_T/2)` 后，另外三个转角由 `(t,q/t,−t,−q/t)` 唯一确定。沿这条曲线前进或返回不算新的分支；把全部转角反号也不会改变下面的乘积选根。动画末态的 130° 是演示范围，不是已证明的运动极限或唯一终态。

**仅固定面片形状和连接关系，并不等于固定初始三维装配。** 对当前模型，可以直接枚举闭合方程的选根：

1. 记 `p_i=x_i*x_(i+1)`、`q=2−√3`，四个顶点的根分别是 `{q,1/q}`、`{−q,−1/q}`、`{q,1/q}`、`{−q,−1/q}`。
2. 四边循环要求 `p_1*p_3=p_2*p_4`。写成 `p_i=(+1,−1,+1,−1)_i*q^s_i`，其中 `s_i=±1`，则须满足 `s_1+s_3=s_2+s_4`，共有六种选根组合。
3. 对每种组合，取非零参数 `t=x_T`，可得 `x_L=p_1/t`、`x_B=p_2*t/p_1`、`x_R=p_1*p_3/(p_2*t)`。当前动画选取全部 `s_i=+1` 的组合。
4. 固定选根后，四条约束 `x_i*x_(i+1)=p_i` 对四个变量的雅可比矩阵在此非退化区间秩为 3，故局部自由度为 `4−3=1`。不同选根不能在当前非退化区间内任意切换。

这里的“六种”是固定 T/L/B/R 编号、合并整体转角反号后的**代数组装分支数**；未按面片重新编号的对称性分类，也没有证明全部分支在整个参数范围内都无碰撞，因此不将它表述为“六种物理上互不等价的折法”。`--audit-branches` 会输出全部六种选根，检查代表姿态的刚性、闭合误差及局部自由度。

自由度与分支数量的区别也可参见原始研究 [Rigid folding equations of degree-6 origami vertices](https://pmc.ncbi.nlm.nih.gov/articles/PMC9006121/) 对构型空间和折叠模式的讨论；本节的六组选根来自本项目的闭合方程推导，不是该论文针对本结构的结论。

## 为什么看起来像在压平

当前演示区间内，网格的实际高度跨度从 **3.265986 降到 2.024193，降低约 38.02%**，因此“变矮”的感觉有真实几何依据。中心面固定，面片绕公共边转动；各面片的边长、内角、平面性均保持，未对顶点坐标做高度缩放，也未让面片弯曲。

默认末态并未平铺：T/L/B/R 四个正方形的平面与中心面的较小夹角分别为 **50°、14.244°、50°、14.244°**，整组顶点仍有 2.024193 的高度跨度。图下方新增这四个倾角和高度，用于区别真实空间变化与投影效果；倾角不是图上方的有符号铰链转角 ρ。

`--check-only` 还直接检验相邻正方形出边向量的几何闭合式：`−cos(λ_i)*cos(ρ_i)*cos(ρ_(i+1)) + sin(ρ_i)*sin(ρ_(i+1)) − cos(λ_i)=0`。当前演示路径各采样点对四个铰链角的约束雅可比秩均为 3，独立确认其局部自由度为 1。这个结论限定在当前模型、初始装配及非退化区间；不是其他初始装配、奇异点处分支切换或完整物理折叠极限的证明。

## 原版背景（其他脚本与旧 GIF）

- **等角网格（isogonal mesh）**：每个顶点周围 4 个扇形角固定；**反等角条件** λ′ᵢ + μ′ᵢ = γ′ᵢ + δ′ᵢ = π。
- 二面角 αᵢ 满足 **Bricard 方程**：(kᵢxᵢ − xᵢ₊₁)(kᵢ′xᵢ − xᵢ₊₁) = 0，其中 xᵢ = tan(αᵢ/2)，
  kᵢ = (sin γ′ᵢ − sin λ′ᵢ) / sin(γ′ᵢ − λ′ᵢ)。
- **Example 3（全等情形）**：λ′₁ = 75°，λ′₂ = 60° ⇒ λ′₃ = 105°，λ′₄ = 120°，γ′ᵢ = λ′ᵢ₋₁；
  9 个面全等于同一个圆内接四边形 Q（边长 1.983 / 1.218 / 1.218 / 0.765，内角 75° / 60° / 105° / 120°）。
- **折叠路径**：分支 k₁K₂k₃K₄ = 1，α₁ 由 0 驱动到 178° 再展开；方向为上侧 T 朝下叠、下侧 B 朝上叠、左 / 右朝下叠。
- **共边贴合**：角面每帧用三点刚性配准跟随相邻两个边中面，12 条共边及全部角点在折叠全程精确贴合（间隙 ~1e-16，机器精度）。
